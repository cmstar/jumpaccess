## 新功能

- **Agent 可通过 MCP 使用 JumpAccess**：CLI 和桌面 GUI 提供同一套 Streamable HTTP MCP 服务，支持查询资源、复用 SSH 连接、执行非交互命令，以及跟踪、取消长任务。命令分别返回标准输出、标准错误和真实退出码；超时、断线或取消后无法确认远端结果时，明确报告状态未知。
- **按名称直接连接**：已知别名、资产名称、地址或 UUID 时可直接指定目标，省略 Profile 时使用当前配置，无需固定先枚举 Profile、别名和资产。目标或账号存在歧义时返回候选与查询范围；连接及文件任务固定首次解析的身份，不随后续配置切换而改变。
- **自动下载远端文件和目录**：优先使用 SFTP，不可用时回退到 `sz`，支持压缩传输、目录和持续追加的日志。本机监听时直接保存到服务电脑；局域网共享监听或本机目录无写入权限时，提供限时下载链接。直接保存的文件已经还原，链接交付会说明需要解开的外层压缩格式。
- **本机上传与 HTTP 中转上传**：服务可直接读取本机文件，自动压缩普通文件或目录；异机来源或服务没有读取权限时，由调用方准备传输包并通过 HTTP 发送。两种来源均优先使用 SFTP、必要时回退 `rz`，先在远端暂存和隔离还原，再发布到目标目录；已有同名文件或目录不会被覆盖或合并。
- **GUI 提供独立 MCP 工作区**：集中管理配置、Token、服务启停、共享连接与调用日志，支持按连接筛选日志和可选的随应用启动。关闭 MCP 页签不停止服务，退出应用时停止。
- **CLI 可独立承载 MCP**：使用 `jumpctl mcp config` 管理配置、`jumpctl mcp serve` 前台运行、`jumpctl mcp status` 查看状态。日志支持三个详细级别和颜色选项，普通日志与错误分别写入 stdout、stderr；Ctrl+C 停止后保留终端已有日志。

## 兼容性与使用说明

- 先完成所需 Profile 的 JumpServer 登录，再启动 MCP。默认地址为 `http://127.0.0.1:39287/mcp`，使用独立 Bearer Token；CLI 与 GUI 共用配置，同一应用数据目录只运行一个实例。`jumpctl mcp config` 会完整显示 Token，保存网络或 Token 配置后需重启服务生效。
- 从本系列预览版升级后，重新启动服务并让 Agent 客户端刷新工具定义，以使用名称直连和 HTTP 上传工具。首次仍需获取服务实例与请求代号；重试保留原请求键，结果未知时先核对原任务，不能换键自动重放。
- 文件传输要求目标提供 POSIX 环境与 Python 3.7+；上传还要求目标目录已存在、可写，并支持排他重命名。上传还原保留名称、内容及目录结构，文件权限为 `0600`、目录为 `0700`，不迁移原权限或时间戳。
- 每项文件传输最多 1 GiB，按实际传输包大小计算。下载链接、上传接收资格及上传收齐后的待提交内容分别有效 30 分钟；停止或重启服务会使旧链接、接收凭据和任务 ID 失效，不删除已发布的文件。
- 开放局域网访问不会自动把本机上传改为 HTTP 中转。HTTP 上传需要调用方能够读取、打包文件并发送正文；接收成功只表示内容到达 JumpAccess，须提交并等待远端任务完成。

## 已知限制

- MCP 面向非交互命令，不提供持久交互 Shell、端口转发、多用户权限隔离或服务重启后的任务恢复；目标访问继续受 JumpServer 权限和策略约束。
- 跨设备局域网与 TLS、macOS 原生 MCP 交互、最低 Python 3.7 环境，以及真实 JumpServer 策略下的上传 `rz` 回退仍需进一步实机验收；自动化测试和平台构建不代替这些场景的验证。

## 新功能

- **CLI 支持承载 MCP 服务**：使用 `jumpctl mcp serve` 前台启动，与 GUI 共用资源查询、SSH 连接复用、命令任务和文件下载能力；`jumpctl mcp status` 可查看服务宿主、实际地址及配置是否需要重启生效。
- **命令行统一管理 MCP 配置和 Token**：`jumpctl mcp config` 不带修改选项时显示全部配置，带选项时只修改指定字段，统一校验、保存后自动回显。支持一次修改多个字段，使用 `--rotate-token` 生成或替换 Token，使用 `--token` 设置已有值；Token 在配置输出中完整显示。
- **CLI 持续显示 MCP 调用日志**：支持精简、标准和详细三个级别，以及自动、强制开启或关闭 ANSI 颜色。普通日志写入标准输出，警告和错误写入标准错误；按 Ctrl+C 停止服务后保留已有日志和终端滚动历史。

## 改进

- GUI 和 CLI 的 MCP 日志时间统一显示为 `MM-dd HH:mm:ss`，便于区分服务连续运行多天时的记录，并保留原有颜色语义。
- 用户指南补充 CLI 配置、启动和日志操作，按 GUI、CLI 的顺序介绍；README 界面预览加入 MCP Server 运行日志截图。

## 兼容性与使用说明

- CLI 与 GUI 共用已有 MCP 配置和访问 Token，无需迁移；同一应用数据目录只允许一个宿主运行。切换宿主时应先停止原服务，旧连接与任务 ID 随之失效。
- 运行期间可以保存配置，但监听地址、TLS 和 Token 在下次启动或重启后才生效。已有配置的用户可以直接运行 `jumpctl mcp serve`；首次配置可先运行 `jumpctl mcp config --rotate-token`。
- 本版仍为预览版。真实 Agent 客户端、macOS 原生交互及跨设备局域网场景仍需进一步实机验收；自动化测试与构建检查不代表这些环境均已完成验证。

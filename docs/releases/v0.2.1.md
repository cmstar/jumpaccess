## 新功能

- **可配置 SSH 终端历史保留行数**：在桌面端“终端行为”中设置 0–50,000 行，默认 10,000 行；统一设置按每个 SSH Tab 独立计算，自动折行也计入额度。设置即时应用于已打开的终端，切换 Tab 和后台接收输出时继续保留历史；设为 0 时不保留屏幕之外的历史。

## 问题修复

- **SSH 重连保留已有输出**：通过回车或工具栏重新连接时，在原终端中追加重连提示和后续输出，失败后再次重试也可查看此前的 SSH 内容。断线时若处于 Vim 等程序的备用屏幕，会将最后画面的文本保留到主缓冲；从未收到 SSH 输出、只有本地连接提示的 Tab 则在重连时清空旧提示。
- **快速连接搜索全部已加载资产**：在当前 Profile 和 Organization 下累计搜索已加载的资产及别名，不再受资产页当前搜索词、分页或 Alias 筛选限制，也不会改变资产页的筛选条件。别名创建、改名、删除和账号绑定会同步更新快速连接结果。

## 兼容性与使用说明

- 旧版 GUI 配置缺少历史行数设置时默认使用 10,000 行，无需手工迁移。历史仅保留在当前 Tab 的内存中，多轮连接共用该 Tab 的行数额度；关闭 Tab 或退出应用后不保存输出，远端程序主动清屏仍遵循正常终端行为。
- 快速连接不会自动预取尚未加载的资产分页；当前上下文没有已加载资产时，继续使用远端快速搜索。切换 Profile、Organization、退出当前 Profile 登录或修改其站点地址后，会清空已加载资产。

# 项目规范

## 用途

本目录存放项目专项规范，以及适用的团队规范摘要和引用。
开发约定总入口见 [development.md](../development.md)。

## 新增与维护

- 需要长期遵守、且不适合在 development.md 中简述的专项约束，单独建立文档并在此登记。
- 文件名按规范主题命名，避免把多个无关主题放入同一文件。
- 文档说明适用范围、具体规则和验证方式；引用外部规范时注明来源，必要时注明版本。
- 项目规则或外部规范变化时，同步更新文档、索引和 development.md 中的引用。
- 项目特例的历史原因记录在 decisions/，此处只保留当前规则并链接对应决策。
- 不全文复制大型公共规范；离线副本需注明来源和版本，并在恢复访问后核对。
- 索引按下表的列名和顺序维护，新增文档时追加一行，文档使用相对链接；无文档时只保留表头和分隔行。

- 实施状态：已实施

## 背景

MCP 分支在共享配置中增加 `[mcp]`，并在 GUI 配置中增加同名分组、将版本号从 14 提高到 15。切回 master 构建后，原有未知字段检查及较高版本号检查使桌面程序无法启动。版本号曾随新增字段递增，不能单凭版本大小判断既有结构不兼容。

## 决策

读取时允许未知字段；较高版本的已知部分仍按当前模型解析和校验。TOML 语法错误、已知字段类型错误、非法值及无效版本号仍报错。旧 GUI 分组迁移继续执行，较高版本号保留。

写入时在既有锁与原子替换流程中重新读取原文件，将当前模型的已知字段更新回去，保留未知字段及较高版本号。字段清空、实体删除必须生效，不能由旧值补回；工作区 Tab 按稳定 ID 匹配扩展字段，避免排序导致串位。旧 GUI 已迁移字段从原分组移除。原文件不可读取或语法错误时停止写入。

不采用“只去掉未知字段检查”的方案，因为模型重新编码会抹掉另一分支的配置；也不为 MCP 设置特例白名单，其他新增字段遵守同一规则。

## 边界与代价

- 未知字段不会在当前程序中生效；字段拼写错误也可能被视为扩展字段，因此已知字段的取值仍应依据文档。
- 保留字段值及 TOML 类型，不保证原有注释、键顺序和排版。
- 不保证已知字段改型、已知枚举新增值或语义变化的跨版本兼容；这类变化仍需单独设计迁移。
- 凭据继续使用既有私有存储，配置扩展不参与认证。

## 验证

覆盖共享配置与 GUI 配置的未知分组、嵌套扩展、较高版本、旧 GUI 迁移、行内表、Tab 排序、已知字段清空及实体删除；通过 CLI 校验与修改、GUI 初始化与偏好／工作区保存验证实际入口。

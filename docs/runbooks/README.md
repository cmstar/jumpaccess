# 操作手册

## 用途

本目录存放部署、回滚、排障、数据修复和事故处理等操作手册，帮助执行者完成具体操作并核对结果。
安装入口见[项目 README](../../README.md)，日常使用步骤见[用户指南](../manual/README.md)，构建、发布与检查流程见[开发说明](../development.md)；独立操作手册在需要交接时建立，并记录实际验证状态。

## 新增与维护

- 操作涉及多个步骤、容易误操作或需要交接时，按操作场景建立手册。
- 文件名按操作目标命名，一份手册聚焦一个可完成、可检查的任务。
- 手册说明适用环境或版本、前置条件和权限、操作步骤、预期结果、失败处理及回滚方式。
- 不可回滚的操作注明限制和执行前的确认要求；一次性流程注明适用范围和失效条件。
- 命令、环境或流程变化时同步更新，实际执行发现问题时及时修正。
- 记录最近验证日期，未验证的步骤明确标注；失效手册标注停用或替代关系，并更新索引。
- 索引按下表的列名和顺序维护，新增手册时追加一行，文档使用相对链接；无手册时只保留表头和分隔行。

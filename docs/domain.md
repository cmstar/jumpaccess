# 业务说明

## 业务场景

JumpAccess 面向需要通过 JumpServer 访问远程 Asset 的用户。用户先独立完成 OAuth 登录，之后可以使用桌面 GUI 或 `jumpctl` 建立直接 SSH 会话，也可以让支持 SSH `ProxyCommand` 的客户端调用 `jumpctl` 作为连接通道。GUI 不提供代理能力。

JumpAccess 负责认证、资源发现、目标解析和连接编排；JumpServer 仍然是用户授权、Organization、Asset、Account 及会话访问策略的权威来源。

## 核心对象

| 对象 | 英文/代码名称 | 定义与关系 |
| --- | --- | --- |
| 连接配置 | Profile | 一个 JumpServer 站点及其本地连接上下文。Organization、Alias 和 Token 状态均在 Profile 范围内解释 |
| 组织 | Organization | JumpServer 中用于隔离资源和权限的组织上下文；资源查询和连接准备可能依赖当前 Organization |
| 资产 | Asset | 由 JumpServer 管理、可建立远程会话的目标资源 |
| 账号 | Account | 在某个 Asset 上用于建立会话的远程账号；同一 Asset 可能存在多个可用 Account |
| 别名 | Alias | 用户在某个 Profile 内为远程目标设置的稳定、本地可编辑名称；至少定位 Asset，也可绑定必要的 Organization 或 Account 以消除非交互连接歧义 |
| 访问令牌 | Access Token | 调用 JumpServer API 的短期 OAuth 凭据 |
| 刷新令牌 | Refresh Token | Access Token 即将过期或已经失效时，用于申请新 Token 的长期 OAuth 凭据 |
| 连接凭据 | Connection Token | JumpServer 为建立具体远程会话提供的短期连接信息；它与 OAuth Token 的用途不同 |
| SSH 会话 | SSH Session | 已经建立的数据通道。建立后不应依赖 OAuth Token 持续有效，也不因后台刷新失败而被主动关闭 |

Alias 固定归属于 Profile，必须定位一个 Asset，Account 可为空。Organization 不是独立归属：GUI 创建 Alias 时根据当前 Profile 的 Organization 查询并验证 Asset，再把该 Organization 与 Asset ID 一并保存；用户不能为同一 Alias 另选一个无关 Organization。绑定 Account 时只能从该 Asset 当前获准的 Account 中选择，清空 Account 表示连接时再询问。

## 关键流程

GUI 的 Profile 卡片在右上角提供“启用”按钮，当前 Profile 显示“使用中”；底部保留认证、编辑和删除操作，空间不足时换行。卡片不展示 Organization。资产页切换组织时仍立即保存到对应 Profile，启动时加载当前 Profile 上次选择的组织；重新启用其他 Profile 时恢复它自己的组织选择，不自动选取组织列表第一项。

### 登录与续期

1. 用户选择 Profile 并执行认证命令。
2. JumpAccess 打开浏览器，完成 OAuth Authorization Code + PKCE 授权。
3. Token 写入当前用户私有的 Profile 独立凭据文件，TOML 中不保存秘密。
4. 程序发起 API 请求时，根据 Token 有效期决定是否刷新。
5. 桌面 GUI 从启动到退出持续按配置周期检查所有已保存 Refresh Token 的 Profile，并自动发现运行期间新增、重新登录、退出登录或删除的 Profile；`jumpctl ssh` 和 `jumpctl proxy` 在各自进程运行期间检查所使用的 Profile。
6. 监督器只在 Access Token 临近过期时请求刷新；刷新结果或失败不得改变现有 SSH Session 的连接状态。

Refresh Token 已失效时，需要用户重新执行交互登录；在凭据变化前，GUI 不重复尝试同一份已确认失效的 Refresh Token。Proxy 模式本身不打开浏览器。

当前 GUI 登录会打开系统浏览器，并要求用户把 JumpServer 确认页中的 `jms://` 链接或完整确认页 URL 粘贴回应用。登录尝试的 state 与 PKCE verifier 只保存在当前 GUI 进程内；私有协议注册与跨进程回调尚未实现。

### 目标解析

1. 根据显式参数或当前设置确定 Profile 和 Organization。
2. 优先在该 Profile 范围内解析 Alias，否则查询 JumpServer Asset。
3. 确定 Asset 和 Account。UUID 格式的 Asset ID 直接查询详情；其他 Asset 引用按每页 100 条搜索，按服务端返回顺序选择首个 ID 精确匹配或名称、地址忽略大小写完整匹配的资产，找到即停止，不检查重名。当前页没有匹配才继续读取后续分页，遍历结束后仍无匹配时报找不到资产；分页失败或无法推进时返回错误。该规则由资源查询与连接准备共用。
4. 直接 SSH 模式可以在终端中对多个 Account 进行交互选择。
5. Proxy 模式按相同规则选择首个匹配的 Asset，Account 必须非交互地确定：优先显式参数，其次 Alias 绑定账号，否则只有一个可用账号时自动使用；多个账号且没有明确选择时直接报错。

### 建立连接

- 直接模式：`jumpctl` 承担 SSH 客户端角色，连接成功后向用户提供交互终端。
- Proxy 模式：`jumpctl` 作为通用 SSH `ProxyCommand` 进程，为外部兼容客户端传输 SSH 协议数据。

两种模式共享认证、资源查询、Alias 解析和 JumpServer 连接准备逻辑，但具有不同的交互约束。

## 业务规则

- Alias 位于 TOML 配置中，允许用户批量直接编辑；项目需要提供打开配置文件的快捷命令。
- GUI 的资产搜索同时匹配远端 Asset 与本地 Alias；合并结果按 Asset ID 去重。远端 Asset API 使用 offset/limit 分页，GUI 资产列表每页请求 100 条，与 CLI `asset list` 的默认分页大小一致。
- “All organizations” 是聚合上下文：选择它时显示各具体 Organization 中与当前资产匹配的 Alias；在该聚合上下文创建的 Alias 切换到具体 Organization 后，只要对应 Asset 可见，也继续显示。
- GUI 在资产行内纵向展示该 Asset 的全部 Alias；资产行的更多操作始终提供创建入口，因此同一 Asset 可以拥有多个 Alias。Alias 可重命名或删除：重命名必须原子保留 Asset、Organization 和 Account 映射，并同步更新匹配的已打开 SSH Tab 重连描述符，但不中断活动 Session；删除必须使用应用内确认对话框，不依赖系统或浏览器原生确认框。资产数和当前 Organization 的 Alias 总数显示在对应表头，Alias 总数不受当前分页影响。
- 资产、Alias 和资产详情按授权协议独立显示 SSH/SFTP 入口；支持 SSH 不代表支持 SFTP。
- 资产行末按 SSH、SFTP、更多操作的顺序显示图标按钮；未授权的连接协议不显示入口。更多菜单保留创建 Alias、复制地址和复制 Asset ID，不重复列出连接操作。从资产行连接时沿用资产账号选择流程，不隐式采用某个 Alias 的绑定账号。
- 资产列表保留不同类别的授权资产，不按 Linux 或 SSH 过滤。列表与详情根据服务端类型、类别标识选择主机、Windows、网络设备、数据库、云服务、Web、目录服务或 GPT 图标；未知类型使用通用资产图标并保留服务端显示名称。图标不决定连接能力。
- 资产详情完整展示当前授权协议；存在 SSH/SFTP 之外的协议时明确说明 JumpAccess 暂不支持哪些协议，同时保留已授权 SSH/SFTP 的操作。协议为空、详情加载中和加载失败分别展示，失败可重试，不能将加载失败解释为没有授权。
- 资产详情展示当前资产的全部本地 Alias，并始终提供添加入口，允许编辑、删除和修改默认账号。详情与列表复用同一套 Alias 操作与确认流程，变更后两处同步；列表原有的多 Alias 展示与操作保留。详情面板加宽，为完整 Asset ID 和复制按钮预留空间。
- SSH Tab 支持会话内 ZMODEM 上传和下载；远端 `rz` 对应本机上传，`sz` 对应本机下载。命令可用性与堡垒机传输授权是独立条件，不从 SFTP 权限推断。上传和下载按钮始终显示，分别检测到能力后启用对应按钮；检测中、未安装、探测失败、断连或传输期间保持置灰，探测失败为未知，手工命令握手仍可启用对应能力。点击按钮前需处于命令提示符。下载按钮接受单个文件路径，不提供目录浏览；多文件可用手工 `sz file1 file2`。传输以 live Session 为单位，切换 Tab 不中断，重连后重新检测；取消、断连或退出会清理未完成的本地下载，同名文件自动另存，不覆盖已有文件。
- GUI 从 Asset 发起连接且存在多个 Account 时必须让用户选择；从 Alias 发起连接时优先使用已绑定 Account，未绑定时同样询问，不能隐式挑选第一个 Account。
- GUI 使用顶部 Tab 工作区：资产、Profile 和设置分别只能打开一个 Tab，SSH/SFTP Tab 可以并行打开多个，以终端／文件夹图标区分协议，标题不追加协议后缀；任意 Tab（包括最后一个）都允许关闭，工作区为空时显示包含新建连接、资产、Profile 和设置入口的起始页。Tab 默认显示关闭按钮，用户可以在设置中隐藏；按钮隐藏后鼠标中键关闭仍然可用。
- GUI 启动并恢复工作区后，如果没有可用 Profile，或当前 Profile 尚未登录，则自动打开并激活 Profile 页面；当前 Profile 已登录时保持原活动 Tab。
- GUI 顶部 Profile 图标右下角的认证状态点以绿色表示已认证，以红色表示未登录或尚未配置 Profile。未登录时不请求 Organization、Asset 等远端资源；请求期间认证失效时，引导用户在 GUI 的 Profile 页面重新认证，不显示 CLI 操作提示。
- GUI 全局提示共用顶部居中的浮层：普通消息为蓝色，3 秒后消失；警告为黄色，5 秒后消失；错误为红色，保留到手动关闭。全部支持关闭，悬停或键盘聚焦时暂停自动关闭，离开后重新计时；重复的同类同文提示合并并重新计时，不同提示可同时显示。提示不挤占页面或终端空间，不抢输入焦点。原全局错误条已并入该组件；表单校验、SSH/SFTP 连接与传输错误仍保留在对应上下文中。
- 手动资产同步、Profile 刷新认证、登录和退出完成时显示普通消息；复制地址、Asset ID、Profile URL 和当前工作目录在剪贴板写入成功后提示，失败显示错误，剪贴板不可用时显示警告。修改 Profile URL 后以警告提醒旧认证已清除、需要重新登录。启动加载、搜索、翻页、自动续期和连续偏好保存不弹出成功通知。
- Profile 页“刷新认证”执行期间显示“刷新中…”、旋转图标并置灰禁用按钮，直到认证刷新及后续状态加载完成；成功提示包含 Profile 名，失败后显示错误并恢复按钮。忙碌状态按 Profile 独立记录，切换 Tab 不清除，也不禁用其他 Profile 的刷新按钮；刷新其他 Profile 不切换当前 Profile。
- GUI 优先使用平台原生 UI 字体，资产、Profile、设置和弹窗等应用界面采用 125% 基准及清晰的标题、正文、说明文字层级；顶部工作区 Tab 保持紧凑的原始字号，SSH 终端内容严格使用终端设置中的原始字号，二者都不随应用界面字体放大。
- “终端行为”中的“下载保存位置”下拉框分为两组：“每次询问”包含“从下载目录开始”（默认）和“从上次目录开始”；“自动保存”包含“保存到下载目录”和“保存到指定目录”。其中下载目录指系统下载目录，上次目录会跨重启保留。指定目录支持输入本机完整路径或通过系统对话框选择。设置保存后作用于下一次传输，工具栏下载与手工 `sz` 共用规则；SFTP 和 CLI 保持各自规则。
- 系统下载目录支持 Windows 目录重定向。记忆模式首次使用或上次目录不存在、不可写时回退到系统下载目录；自动模式下对应目录未设置或不可用时弹窗选择，不静默改为其他目录自动保存。弹窗优先从可用的系统下载目录开始，否则由系统对话框决定初始位置。
- 用户确认选择并通过活动会话目录授权后记录上次目录，跨重启保留；取消、选择失败或授权前断连不更新。自动下载不改变目录历史，临时选择也不更改设置中的指定目录；其他偏好与工作区保存不能覆盖历史。同一批次多文件共用保存目录，同名文件继续自动另存。
- GUI 设置页采用左侧导航和右侧单列滚动内容：外观、终端样式、终端背景图、终端行为、Tab 行为、关于 JumpAccess 分别占据同级独立面板并保留在同一页面；点击导航滚动到对应面板，滚动内容时导航同步选中当前面板，不为每项设置另开页面。应用主题归入外观；终端样式包含公共预览、配色方案、字体、字号、行高及光标；终端行为包含鼠标右键、多行粘贴警告、选中文本时按回车复制，以及桌面 SSH 的 SZ/ZMODEM 下载保存位置；顶部工作区 Tab 的关闭入口和关闭确认归入 Tab 行为。
- 版本精确为 `dev` 时，设置最底部在“关于 JumpAccess”之后显示“开发调试”分组，左侧导航同步增加末尾入口。当前提供普通消息、警告和错误三种提示演示，直接复用公共提示组件，不调用业务 API 或修改配置；后续演示功能在此分组扩展。正式和预发布 tag 版本均隐藏分组及导航，包括形如 `0.2.0-dev` 的版本；浏览器本地预览使用与本地编译一致的 `dev`。这是入口的条件渲染，不保证发布包排除演示代码。
- 终端背景图是所有 SSH Tab 共用的 GUI 偏好，默认关闭、图片透明度 70%。独立面板支持选择／清除本地图片、开关、图片透明度、自适应铺满／完整显示／拉伸／平铺；铺满时提供水平与垂直位置，平铺时提供长边适配终端区域和仅显示完整图块。完整图块整体居中，区域不足时缩小显示一张。背景预览沿用当前终端样式；图片只覆盖终端内容及同色留白，窗口框体、工具栏、Tab、状态栏和 SFTP 不受影响。图片固定在终端可视区域，不随输出滚动；文字透明度与远端指定的字符背景色保持原样。关闭保留路径和参数，清除同时关闭；图片不可读或解码失败时使用终端方案纯色，并在设置页提示原因。
- 终端配色通过一个按“深色 / 浅色”分组的单选下拉框选择，每项显示名称、完整 ANSI 16 色色表和选中标记。内置 28 个方案，包含所采用固定版本的全部 16 款 Windows Terminal 内置配色，以及 Ubuntu 22.04 深浅配色，默认 Nord；选择后自动保存到 GUI 偏好，公共预览与 SSH 终端使用同一配色和字体参数。配色与应用主题独立，只影响终端内容、光标和选区，不改变窗口、菜单、Tab 和连接状态栏；应用主题变化也不得覆盖终端方案。方案控制默认前景、背景与 ANSI 0–15 色，远端程序指定的 256 色扩展槽与 truecolor 颜色不被重映射。
- 公共预览使用隔离的只读 xterm 实例和固定演示文本，不建立 SSH 连接。字体、字号、配色、行高与光标更新不得重建现有终端或重新播放历史；保留已有输出与选区，字体或行高变化时重新适配字符网格并同步终端尺寸。连续修改偏好立即预览、按顺序保存；保存失败时报告错误，只有最新请求失败才恢复最后成功保存的偏好。SSH 终端背景必须铺满标题栏与状态栏之间的整个内容区；文字四周保留 12px 内边距，留白背景与终端底色完全一致，不露出应用背景色。字符网格未占满的余量和加载状态也使用终端配色。
- 行高为默认字符行高的倍数，默认 1.0，配置接受 1.0–2.0 范围内的有限数值；界面提供间隔 0.1 的选项，并保留手工配置的合法中间值。光标支持方块（`block`，默认）、竖线（`bar`）、下划线（`underline`）和底部方块（`quarter_block`，贴底、约四分之一字符格高），样式下拉和闪烁开关位于同一设置行；闪烁默认开启。预览与 SSH 终端共用渲染参数，预览高度随字号及行高调整；预览失焦时仍显示所选光标形状，点击聚焦后查看闪烁，不因修改偏好自动抢走焦点。实际会话遵循 xterm 的焦点与远端控制序列行为，远端程序可临时控制或隐藏光标；选择底部方块时，下划线类光标统一加粗，远端切换方块或竖线仍按原生形状显示。设置不修改应用外层样式。
- GUI 的终端字体设置列出当前系统识别到的等宽字体。展开 Combobox 时始终显示完整列表并标记当前值，只有用户开始输入后才过滤候选项；输入框同时接受未列出的字体名称，并支持方向键、Enter 选择及 Escape 撤销本次过滤。平台枚举不可用或失败时，候选项至少保留通用字体族 `monospace`，新配置也默认使用该系统等宽字体族。
- SSH 终端默认把鼠标右键解释为粘贴剪贴板文本；用户可以在“终端行为”面板中改为打开应用内上下文菜单。菜单包含复制和粘贴：没有终端选区时复制禁用，复制历史输出不要求 Session 仍然在线；只有活动 Session 可以粘贴。右键行为切换立即应用于已打开终端，不得为此重建终端或丢失当前选区。
- SSH 终端默认开启“选中文本时按回车复制”（`terminal.copy_on_enter`）。有终端选区时，普通 Enter 复制选中文本，成功后取消选择，本次按键及松键前的重复事件不得向远端发送回车；剪贴板不可用或复制失败时保留选区，仍拦截本次回车。异步复制完成不得清除后来建立的选区或操作已卸载终端。无选区或关闭开关时保留现有输入规则；断线后有选区时优先复制，无选区的独立 Enter 才触发重连；文件传输期间允许复制历史文本，但仍禁止终端输入。输入法确认和带 Ctrl/Alt/Shift/Meta 的 Enter 不触发复制。设置同时适用于 Windows 和 macOS，保存后立即作用于已有终端，不重建会话；旧配置缺少该字段时默认开启，显式关闭值必须保留。工具栏、上下文菜单和 Ctrl + Insert 的复制仍保留选区。
- SSH 终端的多行粘贴警告默认开启，标题栏按钮、鼠标右键、上下文菜单、`Shift + Insert` 和原生 paste 事件共用同一检测规则。剪贴板文本包含 `CR` 或 `LF` 时，包括单条命令末尾自带换行，必须先以应用内 Modal 显示行数、字符数和可滚动的纯文本预览；取消、断连或 Session 切换不得写入终端，只有用户选择“仍然粘贴”后才按普通用户输入发送。用户可以在“终端行为”面板中关闭警告，切换立即应用于已打开终端且不得重建终端；单行文本始终直接粘贴。
- Profile 与 Organization 选择只影响资产过滤，因此只显示在资产页；新建连接直接打开快速连接窗口，也可以由全局快捷键触发。快速连接优先复用资产页已有数据并在本地筛选，只有资产页没有数据时才请求远端。顶部右侧按资产、包含认证状态的 Profile、设置顺序提供图标入口，认证详情通过 Profile 图标的悬停提示展示。
- 快速连接在同一列表提供 SSH 与 SFTP：点击结果主体或 SSH 按钮连接 SSH，SFTP 按钮独立连接 SFTP；仅授权 SFTP 的资产仍展示，SSH 按钮置灰，主体点击只选中且 Enter 不改用其他协议。打开时聚焦搜索框并选中第一条结果，过滤后重置为第一条；↑↓ 切换选中项并自动滚动到可见位置，Enter 连接 SSH，Shift+Enter 连接 SFTP，Esc 关闭。快捷键在快速连接弹窗处于最上层时生效，不要求搜索框获得焦点；焦点位于按钮或点击空白处后也操作当前选中结果，上下键不执行默认滚动。关闭弹窗后释放快捷键，被其他对话框覆盖时不截获其键盘操作。仅有一条结果时，在搜索框直接按 Enter 即连接该目标；中文输入法确认和长按重复 Enter 不触发连接，准备连接期间拦截重复提交。仅别名匹配时只列出匹配的别名，不附带同资产其他目标。每条结果用单行依次显示加粗的别名或资产名称、灰色的资产名称（仅别名项）、地址和括号内的登录账号；不重复显示资产名称，不显示账号名称、账号 ID 或资产类型，过长内容省略并可悬停查看完整文本。未绑定且仅有一个账号时显示该账号，多个账号时提示连接时选择。绑定失效时禁用连接，不自动换用其他账号。选择账号期间只显示账号弹窗，支持上下键与 Enter，取消后返回原搜索。
- 资产页“立即同步”在当前 Profile 的 Organization 列表为空时，同时重试组织加载（包括启动加载失败或返回空列表）；列表已有内容时只刷新资产。已登录但尚未选择 Organization 时，也可点击该按钮加载组织，选择后再查询资产。组织或资产请求进行中时显示“同步中…”并禁用按钮，失败后允许再次重试；切换 Profile 时清空旧组织选项。
- 手动同步等待本次组织、资产及后续认证状态请求完成后才显示结果，任何请求失败都不报同步成功；切换 Profile、Organization 或查询条件后，不再报告被取消的旧同步。没有可用 Organization 时显示警告；已加载组织但尚未选择时提醒先选择，只加载组织成功时明确提示下一步需要选择组织。
- 资产页和设置页在切换 Tab 时保留当前视图：资产列表与详情栏分别保留滚动位置，设置页保留滚动位置和导航选中项。关闭对应 Tab 后释放视图，重新打开从顶部开始；这些临时位置不写入配置，重启不恢复。
- “Tab 行为”中的“新 Tab 打开位置”提供“所有 Tab 的末尾”（默认）和“当前 Tab 的右侧”。该偏好立即应用于新建的资产、Profile、设置及 SSH/SFTP Tab，并在新建后激活；当前 Tab 位于中间时，右侧模式将新 Tab 插入它与原右邻 Tab 之间。打开已存在的单例页只激活，不移动；恢复工作区保持已保存顺序，没有当前 Tab 时追加到末尾。
- GUI 记住普通窗口关闭时所在的显示器、工作区内位置和尺寸，并在下次启动恢复到同一显示器。目标显示器已断开时回退到主显示器居中；显示器分辨率、缩放或任务栏工作区变化时必须保证整个窗口仍位于可见区域。最大化状态单独恢复，最小化后重新显示不得改变原显示器。
- SSH Tab 标题保持单行：有 Alias 时先显示 Alias，再以弱化文字显示原始 Asset 名；没有 Alias 时只显示 Asset 名。Tab 默认宽度保持 220px，拥挤时可压缩到 44px；紧凑布局收紧按钮间距，极窄时仅显示类型图标和关闭按钮，完整名称仍可通过悬停查看，达到最小宽度后才允许标签栏溢出。Tab 宽度不足时优先分配空间给 Alias：Alias 放不下时只对 Alias 显示省略号并隐藏原始 Asset 名，Alias 完整显示后才将剩余空间用于原始 Asset 名。SSH 与 SFTP Tab 的悬停提示补充 Alias、Asset、ID、Profile、Organization 和 Account；Organization 显示组织名称，Account 优先显示账号名称，缺少时使用用户名或别名，不展示两者的 ID。名称按 Tab 自身的 Profile、Organization 和 Asset 查询，适用于恢复的工作区；查询失败显示“名称暂不可用”，再次悬停或聚焦可重试，成功结果在当前窗口内复用。
- SSH 页面标题栏依次显示 Alias（没有时使用原始 Asset 名）、原始 Asset 名、Asset ID，以及连接状态灯和到 JumpServer SSH 网关的当前往返延迟。活动连接首次探测前显示灰灯与 `— ms`；延迟小于 `100 ms` 显示绿灯，`100–200 ms`（含边界）显示黄灯，大于 `200 ms` 显示橙灯；断开或失败只显示红灯，不显示延迟文字。标题栏右侧依次提供复制选中文本、粘贴剪贴板文本、复制当前工作目录、分隔线、连接 SFTP、ZMODEM 上传和下载、分隔线和最右侧的断开连接按钮。SFTP、上传和下载始终显示，不可用时置灰禁用；SFTP 需活动 SSH 连接且资产授权 SFTP，ZMODEM 按方向检测能力并要求当前无传输。悬停提示分别为 `连接SFTP`、`上传文件到当前目录（rz / ZMODEM）`、`下载文件（sz / ZMODEM）`；不可用时分别为 `连接SFTP （当前不可用）`、`上传文件到当前目录（rz / ZMODEM 当前不可用）`、`下载文件（sz / ZMODEM 当前不可用）`；前两个按钮与终端上下文菜单共用动作，悬停分别提示 `复制选中文本 (Ctrl + Insert)` 和 `粘贴剪贴板文本 (Shift + Insert)`。没有选区时复制禁用，只有活动 Session 可以粘贴；断开按钮只终止可用的 live Session 并保留 Tab，不可用时禁用；关闭 Tab 仍由顶部 Tab 的关闭按钮负责。
- GUI 被动接收远端 Shell 通过 OSC 7 `file://host/path` 上报的绝对当前目录，只在 live Session 内保留最后一次有效值。复制当前工作目录使用目录图标，与复制选中文本按钮区分；收到目录前按钮保持禁用，有效目录变化时才更新，断开、失败或重连时清空，不轮询远端也不自动向 Shell 注入命令。
- SSH Tab 重新挂载时可以向新终端重放已有输出，但重放过程中由终端查询触发的协议响应不得写回 live Session；历史重放完成后才恢复正常输入和实时协议响应转发。
- 远端断开或连接失败不得自动关闭 SSH Tab。终端保留已有输出并追加英文提示 `Connection closed.`、空行和 `Press Enter to reconnect ...`；只有终端获得焦点时的无修饰键 Enter 才能触发重连。
- GUI 保存 Tab 顺序、活动项及 SSH/SFTP 重连描述符，重启后恢复同样的工作区；恢复的连接 Tab 一律保持断连且不得自动连接。终端输出、SFTP 目录与传输队列、live session ID、运行状态和秘密不得持久化。
- SFTP 每次明确连接打开独立 Tab，连接请求未完成时抑制重复点击。SSH 入口使用原连接身份和当前目录快照；资产或 Alias 入口尝试 home，无法获取或访问时静默回退到服务器起始目录。后续浏览不跟随终端。
- SFTP 支持路径输入、隐藏文件、多选、递归上传下载、新建文件夹、重命名与确认删除。单击名称单元格或复选框可切换选中状态；拖选文件名文字供复制时不改变文件勾选状态，文件夹双击进入目录。同名文件由用户选择跳过、覆盖或保留两者，可应用到本批次；失败保留原因，重试从头开始。递归操作跳过已识别的符号链接，不进行断点续传、在线编辑、chmod 或目录同步。
- SFTP 切换 Tab 继续传输；断开保留 Tab，关闭移除 Tab，有未完成传输时必须确认停止。应用退出也先确认未完成传输；取消确认后继续原任务。
- Profile 名是用户可见的精确标识，不为适配文件系统进行替换或规范化；拒绝空名称、首尾空白、控制字符以及 `.`、`..`，其余名称通过稳定摘要映射到凭据文件。
- 创建第一个 Profile 时自动将其设为当前 Profile；已经存在当前项时，后续新建和登录其他 Profile 都不得切换当前项，用户必须显式执行“设为当前”或对应的 `profile use` 操作后才会启用。
- 修改 Profile 的 Server URL 时保留 Profile 名称、Organization 和全部 Alias，但必须清除旧站点的 OAuth 凭据并要求用户重新登录，避免向新地址发送旧站点 Token；已经建立的 SSH Session 不受影响。
- GUI 退出 Profile 登录前必须要求确认；退出会撤销并清除该 Profile 的 OAuth 凭据，但保留 Profile 配置、Organization、Alias 和已经建立的 SSH Session。
- CLI 删除 Profile 时必须在 stderr 明确列出删除范围，并且只有从 stdin 收到精确的 `yes` 后才能执行；其他输入、空输入或 EOF 均取消删除。
- GUI 删除 Profile 会一并清除其 Server URL、Organization、全部 Alias 和本地 OAuth 凭据，并断开该 Profile 的 SSH/SFTP Session 并取消其传输；不会删除 JumpServer 上的 Asset 或 Account。删除当前 Profile 后按名称选择下一个 Profile，没有剩余项时回到未配置状态。
- Token、密码、Cookie 和私钥不得进入 TOML、日志或普通命令输出。
- Access Token 刷新只服务于后续 API 请求和新连接，不得主动终止已经建立的 SSH Session。
- Proxy 模式保持非交互：不打开浏览器、不在 stdout 输出提示、不在账号歧义时要求用户选择。
- Proxy 模式的失败原因写入 stderr 并返回非零退出码，使调用方能够区分未登录、认证过期、账号歧义和连接失败。
- 产品能力以通用 SSH `ProxyCommand` 契约定义；Tabby 只能作为可选配置示例，不能成为业务模型或实现依赖。

## 术语表

- **JumpAccess**：项目和产品名称。
- **`jumpctl`**：首个 CLI 可执行文件名称。
- **JumpServer Client `v4.1.6`**：首个接口和行为参考基线，不是运行时依赖。
- **直接模式**：`jumpctl` 自己承担 SSH 客户端角色。
- **Proxy 模式 / ProxyCommand 模式**：由外部 SSH 客户端启动 `jumpctl`，通过标准输入输出使用其中继能力。它不是“Tabby 模式”。
- **Profile**：本地 JumpServer 连接上下文；不要与 JumpServer Organization 混用。
- **Token**：泛称时可能包括 OAuth Token 与 Connection Token；实现和文档应尽量使用精确名称。

- SSH 顶部工具栏下方按会话显示传输进度区域：空闲不占空间，等待和选择阶段显示不确定进度，传输阶段显示方向、当前文件名、百分比和已传输量／文件大小。保存、远端确认和结束清理阶段禁用取消，完成前最高显示 99%；零字节文件同样等待完成。完成或取消结果保留 4 秒，失败详情保留到手动关闭；切换 Tab 不影响传输，返回时恢复当前状态。底部状态栏继续显示协议、终端类型、连接状态及 ZMODEM 能力提示，本阶段不提供隐藏设置。
